Nintendo Switch2のゲーム紹介

Switch1とSwitch2の違い

Switch 2は新しいNVIDIA T239チップを搭載し、処理性能が向上しています。これにより、より滑らかなゲーム体験が可能になります。

また、Switch 2は画面が大きくなり、新しいJoy-Con 2はマウスとしても使用できます。
